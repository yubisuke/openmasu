# OpenMasu v0.3.0-rc.1

This is a configured prerelease candidate of an auditable, self-hostable mobile
measurement platform. It becomes published only at its matching annotated tag
and GitHub Release, with all full platform workflows green at the exact source
revision. It is not production-ready or a proven replacement for another MMP.

## Changes since v0.2.0

- Reader-only measurement health and exact money, ratio and count displays.
- Saved original ROAS operands, FX, windows and cost selection; unknown,
  historical or removed evidence is not invented.
- Definition-backed comparison meaning, fixed all-page dashboard snapshots and
  neutral aggregate CSV acquisition with explicit units and undefined states.
- One newcomer path from receipt through evidence and comparison.
- Default-off bounded daily cost refresh and explicit selected-cohort correction
  using the existing engine, privacy fences and immutable run supersession.
- Downloadable, version-bound Android AAR/POM, Unity UPM and iOS source assets,
  original manifest, checksums and SDK SBOMs from the same verified CI bundle.

The source/SDK version is `0.3.0-rc.1`. Contract wire/package identity remains
`0.4.0`, through the additive v0.4.10 ledger: 28 schemas, 8 registries,
57 reviewed synthetic fixtures and 741 golden artifacts. Distribution does
not change the SDK API or contract values.

## Evidence and residual boundaries

The [candidate evidence requirements](../validation/v0.3.0-rc.1-synthetic-evidence.md)
bind the full Contract, Runtime, Android JVM/emulator and iOS workflows to the
tag target. The manifest records that same revision. Download verification and
the existing standalone UPM consumer gate are separate from source generation.

All development and acceptance data is synthetic. Real provider credentials,
campaigns, devices, exports, external sends, production hosting, capacity,
backup recovery and operator acceptance remain unverified. iOS is a source
package, not a binary XCFramework. Real Unity 2022.3/iOS exports, physical
devices, store delivery, signing and registry publication remain outside this
release. Checksums are not signatures; a completed window does not prove source
completeness, and provider-side exactly-once delivery is not claimed.

The frozen v0.2.0 tag and historical records remain unchanged. Apache-2.0 applies.
