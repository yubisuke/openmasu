## Evidence boundaries

The runtime's recommended setup journey verifies an empty app, guided
preview/confirmation, authenticated HMAC SDK HTTP sessions, durable inbox
processing, retention, saved analysis and CSV. Its acquisition, cost and revenue
are fixture-projected. It does not load a distributed native SDK.

The new downloaded Android SDK journey proves that separate native/backend
connection. It does not turn the fixture-projected acquisition/cost/revenue
journey into device evidence, or establish iOS/Unity native-to-backend execution.
Correction, privacy, backup and upgrade remain owned by the existing suites
linked above rather than repeated inside the SDK test.

No real data, provider credentials, devices, campaigns or external measurement
sends were used. Live provider permissions/quotas, devices, store approval,
domains, production deployment/capacity/recovery, Unity 2022.3 and consumer iOS
exports remain unverified. The release claims neither production readiness nor
universal MMP replacement or provider-side exactly-once delivery.
