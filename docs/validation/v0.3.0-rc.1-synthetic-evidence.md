# v0.3.0-rc.1 Synthetic Evidence Manifest

This document defines the public candidate's required evidence. It becomes a
frozen record only when the annotated `v0.3.0-rc.1` tag and GitHub prerelease
identify the same green `main` commit. Until then it is a requirement, not a
claim that a prepared bundle has been published.

## Required exact-commit gates

- Full `main` push or manual workflows: Contract on Linux/Windows, Runtime,
  Android JVM, API 36 emulator and iOS Swift/Simulator. PR path-reduced no-op
  results are not accepted as release evidence.
- `npm run validate`: 767 pass / 0 fail, ending with:

  `Validated 28 schemas, 8 registries, 57 reviewed fixtures, 741 golden output artifacts, 57 scenario assertions, 27 acceptance criteria, deterministic TypeScript, independent Python, and RFC 8785 conformance.`

- Existing runtime integration, role grants, privacy restore, PostgreSQL/JCS
  parity, SQL metric parity, financial and dashboard consistency gates.
- Existing disposable pilot, informational load and complete resource cleanup.
- Clean same-revision SDK generation, two byte-identical bundle trees, standalone
  generated-UPM consumer, Android/iOS source parity and SDK SBOM validation.
- Download the exact full Android run's `openmasu-sdk-release-bundle`; its
  `source_revision` equals the tag target and SDK version equals `0.3.0-rc.1`.
- Post-tag `--verify-only --verify-tag --release-assets` reuses the existing
  inventory/checksum/identity verifier before producing public assets. The
  original inner bundle is not rebuilt or altered at a later source revision.
- Download all eight public assets again, verify outer checksums and the inner
  bundle, and bind the public manifest to the same tag and successful runs.

## Identity and lookup

Use `git rev-parse 'v0.3.0-rc.1^{commit}'` for the immutable source revision.
The Release page records the exact Actions run URLs and asset inventory. The
downloaded manifest and Actions artifact must name the same revision. Neither
the historical v0.2.0 manifest nor later `main` results substitute for that gate.

The contract remains `0.4.0` through v0.4.10, with 57 reviewed fixtures and
741 goldens unchanged. SDK/version-bearing source, notes, artifact paths and
SBOM metadata move together without changing contract or runtime behavior.

## Explicitly unverified

No real data, credentials, devices, campaigns, provider sends, store tracks,
domains, deployment, representative capacity or operator acceptance is used.
Real Unity 2022.3 and iOS export, physical-device delivery, live permissions,
quota/duplicate behavior, distribution signatures and registry publication
remain unverified. Synthetic load is informational, not a production SLO.
