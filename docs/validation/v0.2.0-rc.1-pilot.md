## Onboarding findings

The pilot found documentation gaps rather than a runtime or contract defect:

- the quickstart did not distinguish a disposable volume reset from a retained
  deployment;
- the seed example required ingestion quiescence but did not show how to stop
  and restart writers;
- CSV and allowlist examples used Bash syntax without PowerShell equivalents;
  and
- the CLI cost example intentionally produced zero ROAS without pointing to the
  reviewed non-zero revenue-and-cost cohort in fixture 33.

The follow-up documentation change corrects those steps without changing the
published tag, contract identities, reviewed golden fixtures, dependencies, or
GitHub Action pins.

## Residual operator boundaries

The following remain unverified and must stay separate from this synthetic
pilot:

- production hosting, TLS, secret management, alert ownership, incident
  response, and representative capacity;
- real backup retention and recovery objectives;
- package signing and registry publication;
- live provider credentials, exports, acceptance, quotas, and diagnostics;
- physical devices, store tracks, campaigns, domains, propagation, reinstall
  behavior, Unity exports, and consumer-project acceptance; and
- the private M1.5 shadow-pilot decision using authorized real data.

Private pilot results, credentials, identifiers, provider responses, and real
campaign or financial values must not be committed to this public repository.
