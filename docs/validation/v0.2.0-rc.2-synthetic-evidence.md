# v0.2.0-rc.2 Synthetic Evidence Manifest

This manifest defines the public, synthetic-only evidence required for the
`v0.2.0-rc.2` release candidate. The tag and GitHub prerelease must point to the
same `main` commit, and every required workflow must be green for that commit.
This document does not claim production, provider, device, or operator
validation.

## Host and contract gates

- `npm run pilot:preflight` on a clean tree verifies Node.js 22.18.0, npm
  11.6.2, Python 3.13.5, the complete contract gate, unit tests, and the
  source-only iOS check.
- `npm run validate` must end with:

  `Validated 28 schemas, 8 registries, 56 reviewed fixtures, 728 golden output artifacts, 56 scenario assertions, 27 acceptance criteria, deterministic TypeScript, independent Python, and RFC 8785 conformance.`

- Contract v0.4 package versions, schema IDs, fixtures, and reviewed golden
  artifacts must be unchanged from `v0.2.0-rc.1`.

## Disposable Runtime gate

The pinned Runtime workflow runs
`npm run pilot:synthetic -- --disposable --load`. Its bounded JSON evidence must
report a passed status for Compose configuration and startup, empty-ledger demo,
reviewed fixture seed, PostgreSQL/JCS parity, runtime restart and smoke checks,
informational synthetic load, cleanup, and cleanup verification. Every boundary
for real data, external providers, physical devices, production, and operator
acceptance must remain `false`.

The pilot stages tracked source into a temporary directory, strips OpenMasu,
Docker-context, proxy, npm, Node, and credential-bearing parent variables from
child processes, forces providers off, uses a run-unique Compose project and
loopback ports, and removes its containers, network, volumes, generated secrets,
and staging directory.

## SDK release gate

- Android acceptance and five release AAR builds pass.
- Android, iOS, and Unity CycloneDX SDK SBOMs are generated.
- `python tools/build-sdk-release.py --reproducibility-check` produces two
  byte-identical trees for `openmasu-sdk-0.2.0-rc.2`.
- `npm run check:sdk-release` verifies exact contents, Maven POM versions,
  archive structure, SBOM format, and complete `SHA256SUMS` coverage.
- Contract, Runtime, Android JVM, Android emulator, and iOS SDK workflows are
  green at the exact tag target.

## Verification lookup

The immutable source SHA is the target of the annotated `v0.2.0-rc.2` tag. The
GitHub release page and Actions checks for that SHA are the authoritative run
and artifact references; a pre-merge run is not substituted for the tag-target
checks.

## Explicitly unverified

No real export, credential, provider authorization, campaign value, device
identifier, physical device, store track, Unity export, App Store review,
production deployment, external secret manager, real backup, representative
capacity, registry publication, or distribution signature is used or validated.
The synthetic load record is informational and is not a production service
level objective.
