# Historical Issue Drafts

This directory preserves early issue text for contract history. It is not a
live backlog or implementation checklist. The active product sequence is in
[`docs/roadmap.md`](../docs/roadmap.md), current evidence is in
[`docs/STATUS.md`](../docs/STATUS.md), and normative behavior is in the
[Contract v0.4 specification](../spec/event-metric-contract-v0.4.md), schemas,
registries, and reviewed fixtures.

Do not create or update a GitHub issue from these drafts without revalidating
the current source and receiving explicit authorization for that GitHub
operation.
